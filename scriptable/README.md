# 臺大課表 iOS / iPadOS Scriptable 桌面小工具

本目錄提供專為臺大學生打造的 **Scriptable 桌面課表小工具** 腳本與架構。

## 特色亮點

- **自適應多尺寸支援**：
  - **大尺寸 (Large 4x4) / iPad 特大尺寸 (Extra Large)**：
    - **【週課表矩陣】**：顯示週一至週五整週 5 欄課程格子與節次。
    - **今日高亮**：當天欄位自動發光並標記綠點，一目了然。
  - **中尺寸 (Medium 4x2)**：
    - **【今日焦點與時間軸】**：左側實時顯示當前上課中 / 下一堂課教室與時間倒數；右側列出今日課表時間軸。
  - **小尺寸 (Small 2x2)**：
    - **【精簡下堂課】**：極簡卡片快速查看下堂課名稱與教室。
- **Siri 語音互動**：
  - 「嘿 Siri，我接下來有什麼課？」會自動朗讀目前上課狀態或下一堂課教室。
- **深色磨砂玻璃視覺**：
  - 配合 iOS 深色模式與現代毛玻璃漸層，視覺精緻且不耗電。
- **純本地無雲端依賴**：
  - 課表直接內嵌於 JavaScript 腳本中，零伺服器維護成本，保障隱私。

## 使用步驟

1. 至 App Store 安裝免費的 **[Scriptable](https://apps.apple.com/app/scriptable/id1405459188)** App。
2. 前往 [臺大課程日曆好朋友](https://annie04082020.github.io/ntu-course-calendar/) 網頁。
3. 勾選或匯入您的課表後，點擊頂部 **「📱 iOS 小工具」**。
4. 點擊 **「一鍵複製 Scriptable 腳本代碼」**。
5. 打開 Scriptable App，點擊右上角 **「+」** 建立新腳本，將代碼貼上並命名為 **「臺大課表」** 儲存。
6. 回到 iPhone / iPad 桌面，長按空白處 ➔ 點擊左上角「+」➔ 搜尋「Scriptable」➔ 選擇喜歡的尺寸並新增即可！
